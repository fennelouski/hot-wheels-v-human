**Music status (2026-08-24):** every music loop in `Resources/Audio/` is a **synthesized
placeholder** (generated by `tools/generate_placeholder_music.py`, stdlib only, no license
concerns — ours). Replace with real tracks from the sources above when a human picks them;
ducking/looping code won't change.

| Track | Where it plays |
|---|---|
| `workshop_ambience.m4a` | builder/customizer |
| `race_intensity.m4a` | the radio's **8-BIT** preset (and so the default race music) |
| `radio_rock` `radio_jazz` `radio_pop` `radio_funk` `radio_smooth` .m4a | the other five presets |

The six presets are the cockpit radio on the FPV dashboard (`RadioStation`). Regenerate one
without churning the others' committed m4a: `python3 tools/generate_placeholder_music.py
radio_funk`. No arguments rewrites all seven. Every station is level-matched to the same RMS
so tapping across presets doesn't jump in volume, and fades over its last 15 ms so the loop
point doesn't click — `level()` in the tool. 8-BIT has no file of its own on purpose:
`race_intensity` is already a chiptune loop.

Implementation notes
- TV: `AudioFileResource` attached to car entities → spatial audio follows the cars. Engine loop via `prepareAudio` + playback rate mapped to speed (clamp 0.8–1.6×).
- iPad: plain `AVAudioPlayer` for UI sounds/music; duck music −8 dB during countdown & finish fanfare.
- Keep WAV for SFX (latency), AAC/m4a for music (size). Target < 10 MB total audio.
- Log every downloaded file's source URL + license in this README when added (same discipline as Graphics/).
